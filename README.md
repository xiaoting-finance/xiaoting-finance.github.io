# 肖蜓个人网站 V1 / Xiao Ting Personal Website V1

## 文件
- index.html：完整双语网站（CSS/JS 已内置）
- assets/profile.jpg：从简历中提取的个人照片（如简历中存在可用照片）

## 本地查看
直接双击 `index.html` 即可在浏览器打开。

## 上线方式
可直接把整个文件夹部署到 GitHub Pages、Vercel、Netlify 或任意静态网站托管服务。
如果之后购买了个人域名，再把域名绑定到托管服务即可。

## V1 设计原则
- 中英文一键切换
- 强调金融 / 债券 / 风险分析定位
- 首页突出可量化经历，而不是把网站做成“网页版简历”
- 手机端响应式适配
- 目前只公开邮箱，没有公开手机号码
